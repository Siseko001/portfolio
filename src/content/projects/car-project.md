## Overview

This project explores a dataset of car listings to understand how price relates to
mileage and brand, then builds a predictive model to estimate a car's price from
its listing features.

## What it does

- Cleans and prepares raw car listing data for analysis
- Visualizes relationships between **price and mileage**, and compares pricing
  trends **across different brands**
- Engineers features from the listing data
- Trains a **random forest regression** model to predict car price

## Tech stack

Python, pandas, matplotlib/seaborn for visualization, and scikit-learn for the
predictive model.

## Key steps

1. Data cleaning and preprocessing
2. Exploratory data analysis (price vs. mileage, brand-level comparisons)
3. Feature engineering
4. Random forest regression for price prediction
